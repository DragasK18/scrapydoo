Descarga de catálogos

Baja el catálogo completo de una farmacia (laboratorio, marca o categoría) a Excel: precio, precio de lista, INVIMA, PUM, código de barras y stock.

Abre la farmacia en tu navegador, busca un laboratorio o marca y copia la URL de resultados. Pégala aquí (una por línea). Soportadas: Farmanorte, Tu Droguería Virtual, La Rebaja Virtual y Farmacias Pasteur.

Catálogo Makro

Sube el Excel PRODUCTOS_MAKRO con columnas Regular (SKU Makro), Descripción y Ean para que las búsquedas por código de barras consulten tienda.makro.com.co correctamente. También puedes importar un archivo con EAN, Nombre y PVP para comparar tu precio de lista.

Columnas: Regular (SKU), Descripción, Ean. Opcional: PVP, Categoría, Costo, Marca.

Carga masiva

Procesa cientos de productos desde un Excel. Puedes usar una sola columna Codigo_o_Nombre (detecta automáticamente si es EAN o nombre del producto), o columnas separadas EAN / Descripcion. Columnas opcionales: Costo, Categoria (usar fruver), Ciudad (código tienda o nombre), Margen_Objetivo (%).

Solo si la fila no trae margen
Opcional si el Excel trae columna Ciudad
